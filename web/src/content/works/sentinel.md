SENTINEL is an enterprise operational-risk and resilience simulator that models organizational dependencies as a graph and simulates failures to determine technical propagation, business impact, financial exposure, recovery requirements, and response strategies.

It combines dependency-graph traversal, failure propagation, single-point-of-failure analysis, critical-path analysis, risk scoring, recovery modeling, and simulation-based impact analysis in an interactive decision-support environment.

The README deliberately distinguishes genuinely implemented functionality from planned functionality, so the portfolio description focuses on implemented features.

## Key Features

- **Risk Simulation**: Genuine Monte Carlo simulation using normal/log-normal sampling
- **Failure Analysis**: Single-point-of-failure detection and critical path analysis
- **Impact Modeling**: Business impact and financial exposure calculation
- **Recovery Strategies**: Weighted scoring of recovery approaches
- **Interactive Visualization**: Real-time graph-based decision support

## Technologies

ASP.NET Core MVC, C#, PostgreSQL, Redis, EF Core, Docker
