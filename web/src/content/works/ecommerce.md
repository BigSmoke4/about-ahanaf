A responsive database-driven e-commerce web application built with ASP.NET MVC and Razor Views, featuring mobile-friendly interfaces, dynamic Razor rendering, product management, multi-user shopping-cart functionality, and separation of concerns through the MVC architecture.

## Key Features

- **Responsive Design**: Mobile-friendly interfaces that work across devices
- **Product Management**: Full CRUD operations for products and categories
- **Shopping Cart**: Multi-user shopping cart with session management
- **MVC Architecture**: Clean separation of Controllers, Models, Services, and Views
- **Database Integration**: Entity Framework with SQL Server for data persistence

## Technologies

ASP.NET MVC, C#, Razor Views, Entity Framework, SQL Server, HTML/CSS/JavaScript
