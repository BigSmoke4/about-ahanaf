NIRBHOR is a bilingual AI administrative-agent platform designed to help users navigate tasks such as NID correction and passport renewal through English, Bangla, Banglish, and mixed-language conversations.

It combines language detection, Banglish normalization, intent analysis, structured task planning, tool-policy enforcement, tool execution, verification, AI responses, real-time SignalR updates, cost tracking, prompt management, audit logging, and role-based access control.

**Important Implementation Note**: The repository explicitly states that government submission integrations are simulated and that pgvector is not yet implemented, so those are not presented as production integrations.

## Key Features

- **Bilingual Support**: English, Bangla, Banglish, and mixed-language processing
- **Task Planning**: Structured planning for administrative workflows
- **Tool Execution**: Safe execution with policy enforcement and verification
- **Real-time Updates**: SignalR-based live progress monitoring
- **Cost Management**: Token usage tracking and budget control

## Technologies

ASP.NET Core MVC, C#, PostgreSQL, EF Core, Identity, SignalR, Anthropic
