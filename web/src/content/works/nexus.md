NEXUS is an AI-assisted supply-chain crisis decision-support platform that models supplier, product, factory, and customer dependencies as a graph. It provides deterministic disruption simulation, inventory depletion analysis, single-point-of-failure detection, alternate-path discovery, revenue-at-risk estimation, service-level analysis, recovery-time calculation, multi-scenario comparison, and evidence-based AI explanations.

The platform also includes multi-tenant authorization, audit logging, SignalR-based real-time updates, background simulation processing, contract retrieval, OpenTelemetry observability, and Docker deployment.

## Key Features

- **Graph Intelligence**: Models complex supply-chain dependencies using graph algorithms
- **Disruption Simulation**: Deterministic what-if analysis for supply chain disruptions
- **Risk Assessment**: Revenue-at-risk estimation and service-level analysis
- **Real-time Updates**: SignalR-based live monitoring and notifications
- **Multi-tenant Architecture**: Role-based access control and audit logging

## Technologies

ASP.NET Core MVC, C#, PostgreSQL, EF Core, Redis, SignalR, Docker, OpenTelemetry
