Local Agent Platform is a local-first autonomous software-engineering platform designed to plan, execute, verify, and maintain coding tasks without requiring a cloud LLM. It supports persistent agent sessions, model-driven DAG planning, dependency validation, controlled parallel execution, retry and repair budgets, human approval gates, verification loops, repository indexing, Roslyn-based code analysis, semantic memory, authenticated APIs, and real-time telemetry.

## Key Features

- **Local-First Architecture**: Complete autonomy without cloud LLM dependencies
- **DAG Planning**: Model-driven task planning with dependency validation
- **Code Analysis**: Roslyn-based repository indexing and symbol extraction
- **Memory System**: Layered short/long-term memory with semantic retrieval
- **Safety Controls**: Human approval gates and verification loops

## Technologies

ASP.NET Core, C#, PostgreSQL, EF Core, Ollama, Roslyn, SignalR, Docker
