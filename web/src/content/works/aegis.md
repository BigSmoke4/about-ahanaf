AEGIS is an SRE/AIOps incident-response platform that models infrastructure dependencies and guides operators through the incident lifecycle from failure detection to root-cause analysis, business-impact assessment, and remediation.

It implements graph-based cascading-impact analysis, anomaly detection, incident correlation, root-cause ranking, synthetic business-impact analysis, remediation runbooks, approval gates, background processing, and automated testing.

## Key Features

- **Incident Lifecycle**: Complete Failure→Detection→Correlation→Root Cause→Impact→Remediation pipeline
- **Anomaly Detection**: Rolling z-score statistical analysis for identifying anomalies
- **Graph-Based Correlation**: Infrastructure dependency graph for incident correlation
- **Root-Cause Ranking**: Weighted algorithms for prioritizing root causes
- **Synthetic Impact**: Business-impact analysis and human-approved remediation runbooks

## Technologies

ASP.NET Core MVC, C#, PostgreSQL, Redis, EF Core, Docker, xUnit
