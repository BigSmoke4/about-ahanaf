FORGE is a software-engineering intelligence platform that analyzes repositories, understands architecture and evolution, evaluates code changes, and generates deterministic, evidence-backed risk assessments for software changes.

It combines compiler/AST analysis, repository indexing, dependency graphs, Git-history mining, security analysis, architecture validation, technical-debt detection, contextual retrieval, and optional AI reasoning. Its modular architecture uses strict module boundaries enforced through automated architecture tests.

## Key Features

- **AST Analysis**: Roslyn-based semantic code analysis and symbol extraction
- **Dependency Graphs**: Automatic construction of code dependency relationships
- **Security Scanning**: Deterministic security pattern detection and vulnerability analysis
- **Architecture Validation**: Automated enforcement of modular boundaries and policies
- **Git Intelligence**: History mining and change impact analysis

## Technologies

ASP.NET Core, C#, Roslyn, PostgreSQL, EF Core, Git, Docker
