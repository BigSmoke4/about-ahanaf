NEURA is a multi-agent AI orchestration platform that coordinates multiple AI providers around shared missions while maintaining task continuity across context limits. It monitors agent context usage, creates validated context handoff packages, routes work between providers, and provides real-time mission visualization through a neural-graph interface.

The platform also includes persistent execution history, audit logging, provider abstraction, memory, retry and resilience mechanisms, secure credential handling, cost tracking, Docker deployment, and automated testing.

## Key Features

- **Multi-Provider Orchestration**: Seamless coordination between OpenAI, Anthropic, and Google AI
- **Context Continuity**: Intelligent context handoff packages maintaining task coherence
- **Real-time Visualization**: SignalR-based neural graph interface for mission monitoring
- **Resilience Patterns**: Retry, backoff, circuit breakers, and rate limiting
- **Cost Management**: Token usage tracking and budget control

## Technologies

ASP.NET Core MVC, C#, PostgreSQL, EF Core, Redis, SignalR, OpenAI, Anthropic, Google AI
